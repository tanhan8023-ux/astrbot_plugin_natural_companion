# 自然主动聊天（AstrBot 插件）

`astrbot_plugin_natural_companion` 是一个面向单个 QQ/OneBot v11 私聊的 AstrBot 插件。
它会参考当前会话的人设、近期对话、未完话题、情绪和结构化状态，谨慎地决定是否主动找你聊天。

它**不是固定定时器**：插件没有每隔几分钟轮询发送的循环。每次用户消息只可能创建一个随机延迟、可取消的一次性主动机会；如果用户再次发消息、暂停插件、达到频率限制或模型判断不自然，消息都会被取消或跳过。

## 安装

将整个插件目录复制到：

```text
AstrBot/data/plugins/astrbot_plugin_natural_companion/
```

目录至少包含：

```text
metadata.yaml
_conf_schema.json
main.py
core.py
```

首版按 AstrBot 4.x（最低 4.5.7）和 `aiocqhttp`/OneBot v11 适配器设计。插件不接入天气、新闻、日历等外部信息。

## 使用

在目标 QQ 私聊中发送：

```text
/主动聊天 开启
```

常用命令：

```text
/主动聊天 开启
/主动聊天 暂停
/主动聊天 状态
/主动聊天 重绑
/主动聊天 清除记忆
/主动聊天 解绑
/主动聊天 帮助
```

也支持不带斜杠的形式，例如 `主动聊天 开启`。

- **开启**：把当前私聊绑定为唯一主动聊天会话。
- **暂停**：停止主动发送，并取消已经等待中的主动机会。
- **状态**：查看当前开关、心情摘要、未完话题数量和待判断机会，不显示完整提示词或聊天原文。
- **重绑**：把主动聊天会话切换到当前私聊。非绑定会话需要 AstrBot 管理员权限。
- **清除记忆**：清除插件保存的状态，不删除 AstrBot 原有会话历史。
- **解绑**：清除绑定和插件状态。

直接发送以下完整短句也会暂停主动聊天：

```text
别主动找我
不要主动找我
先别主动找我
暂停主动聊天
```

## 行为说明

插件保存的是轻量结构化状态，不保存完整聊天记录：

- 机器人当前心情；
- 当前情景；
- 未完话题；
- 值得后续提起的记忆线索；
- 关系氛围；
- 与主动聊天有关的用户边界；
- 最近主动消息结果。

状态会在短暂防抖后由当前聊天模型抽取。真正发送前会再次由模型判断，要求消息符合当前人设、自然简短、不责怪用户、不制造压力。

默认安全限制：

- 主动消息间隔至少 45 分钟；
- 24 小时最多主动发送 2 条；
- 默认 00:00–07:00 不主动发送；
- 同时最多存在一个待判断主动机会；
- 用户新发消息会取消旧的待发送机会；
- 模型调用失败、返回非法 JSON 或 OneBot 发送失败时，本次机会安全结束，不连续重试。

## 配置

AstrBot WebUI 会读取 `_conf_schema.json`。可以调整：

- 主动机会随机延迟范围；
- 主动消息最短间隔和 24 小时上限；
- 安静时段；
- 状态抽取防抖时间；
- 有具体理由和自然问候的阈值；
- 是否允许没有具体话题时进行轻量问候；
- 调试日志。

## 数据位置

插件状态默认保存为：

```text
data/plugin_data/astrbot_plugin_natural_companion/state.json
```

写入使用临时文件替换，避免进程中断造成半写入文件。删除该文件或使用 `/主动聊天 清除记忆` 可以清除插件状态。

## 本地测试

纯逻辑测试不需要安装 AstrBot：

```bash
python -m unittest discover -s tests -v
python -m py_compile core.py main.py
```

OneBot v11 联调时，建议先在 `_conf_schema.json` 中临时把延迟和防抖改小，验证通过后再恢复为较自然的默认值。
